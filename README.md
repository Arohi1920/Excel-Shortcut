Excel: Separate Text and Numbers
1.	Select the entire data where you want to separate the text and numbers. 
2.	Press Ctrl + G to open the Go To window. 
3.	Click on Special. 
4.	Select Constants. 
5.	Under the options, select only Text and uncheck the other options. 
6.	Click OK. Excel will select only the cells containing text. 
7.	Press Ctrl + C to copy the selected text cells. 
8.	Select the destination cell/column where you want to paste the text. 
9.	Press Ctrl + V. 
10.	Now, you will have only the Text values in the selected column. 
Shortcut: Ctrl + G → Special → Constants → Text → OK → Ctrl + C → Ctrl + V
